# AresRPG active decisions

`ARCHITECTURE.md` owns the current system model. This file keeps active domain rulings whose motive
must survive the conversation that produced them. Search the domain being changed; do not treat
the file as a second architecture. One line owns each ruling. When a ruling changes, amend or
delete its row; superseded decisions never remain.

## Patterns — how to think here

- 2026-08-26 · SOCIAL DOMAINS SHARE AUTHORITY, NOT STATE (owner, amended after adversarial audit): Friends, Party, and Trade keep separate reducers and SDK action hands; authentication/session owns none of their rows. The existing `FriendRegistry` stores one boolean membership marker per character, so one character cannot inhabit two parties without duplicating which Party owns it. FriendList, Party, and Trade object writes are their realtime invalidation facts; existing shared-object actions return certified completion only, while one bounded latest-wins projection owns each mutable row. Creation receipts that project a new shared identity explicitly request `objectTypes`; leave/disband stays optimistically hidden and pending through receipt success until `packet/party: null`, so a dead party id can never be reused in the projection gap. Friends remain a directed whitelist, Party remains character-keyed, and Trade remains version-pinned escrow whose public claim doors never expose the counterparty's transferable PurchaseCap.
- 2026-08-26 · EVERY CERTIFIED TRANSACTION SPEAKS ONCE (owner): the SDK execute boundary permanently logs one pink `tx` row with digest and net SUI cost for every submitted receipt; its SUI breakdown is computation + storage − rebate, with success/failure retained as data rather than label decoration. Preflight refusals have no digest or gas and therefore never impersonate a sent transaction. Individual action modules never add their own transaction logs.
- 2026-08-26 · LOCAL REPIN IS ONE DISPOSABLE CEREMONY (owner): `bun run repin:local` reads one testnet lineage from `pins.json`, rebuilds the current indexer/server images, deletes only the named local FalkorDB projection, starts the indexer with game-original/game-latest/seed-original, waits until it reaches the checkpoint observed before reset, then exposes the server. Hand-written `docker run`, retained cross-lineage graphs, and a server racing an empty projection are forbidden.
- 2026-08-26 · FIGHT BOARDS CUT THROUGH WORLD WATER (owner underwater-board incident): a mounted tactical board extends the existing peephole through the world water surface and suppresses camera immersion for the board lifetime; surrounding water remains rendered, and unmounting restores normal water without inventing a surfacing splash.
- 2026-08-25 · DISCOVERY COMPLETES WITH ITS POPULATION (owner): a zone-search success waits for both the projected `ZoneRow` and its seed-derived `packet/zone_spawns`; the retained 2.5-second center reveal reports individual mob members, total resource nodes, and whether a dungeon portal was spotted—never a generic toast. The transaction receipt alone and the zone row alone cannot produce the summary, and the client never reruns zone RNG.

Invisibility expiry projects an ordered visibility edge before the following turn cue, so targeting truth and the rendered body become visible together.
- 2026-08-25 · THE GATHER ROOT IS A VISIBLE CLIENT ACTION (owner abort-305 incident, amended automatic-ambush ruling): `gather_time_ms` remains the chain-authored 12s→2s post-harvest root, mirrored once in immutable. Receipt latency may extend the conservative fallback but can never unlock before chain truth.
