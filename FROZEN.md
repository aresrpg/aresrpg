# FROZEN — the argue-proof anchors and the rules no one may tune

The frozen-node constitution: rules no optimizer — human or agent, lead included, future-us
included — may tune, precisely because they are the rules pressure will tempt us to bend. Changing
this file is a visible, reviewed act (CODEOWNERS-protected); the conscience loop audits reality
against it and files an issue on any breach. The article's law, made a file.

## Anchors (argue-proof measurements — no argument may reclassify them)

1. **Chain readback.** What the chain returns IS the truth of what was minted/committed.
2. **Executed-suite exit codes.** A suite that ran and exited nonzero is red. Red is a fact, not
   an opinion.
3. **Captured-reality capsules & the fixture corpus.** A recorded timeline is evidence; replay
   verdicts bind.
4. **Production violation-rate.** The tripwire counters ticking in real clients (per release)
   cannot be argued with — only fixed.
5. **Maintainer live play.** The terminal judge, outside the machinery, by design.

## Frozen rules

1. **Nothing reaches production except through the deploy workflow.** No human push path exists.
   The only bend is the break-glass workflow: owner approval required, permanently recorded.
2. **Nothing merges to master except from edge.** Hotfixes ride edge. One direction, always.
3. **Baselines only shrink.** Every ratchet (CodeQL, semgrep, depcruise, mutation score, coverage)
   moves one way; `--rebaseline` is an explicit reviewed act with a written adjudication.
4. **A red anchor is never reclassified by argument.** Red → "rig noise" requires a committed
   fixture PROVING the rig bug, authored by a non-author of the code under test.
5. **The fixture corpus is append-only for builders.** Mutating or deleting an existing fixture is
   an adjudicated act by a non-author (a golden change = a rules change, cited in the commit).
6. **Loops file issues; they never push fixes** and never touch chain, money, or config.
7. **The conscience loop's script, this file, the sanitizer patterns, and the workflow files are
   guard-class** — CODEOWNERS-gated, and the conscience audits its own guards' integrity first.
8. **No secrets in fork-facing CI.** Workflows triggered by fork PRs run with zero secrets;
   `pull_request_target` + PR-code checkout is banned.
9. **The read layer never writes.** The rpc serves; it accepts nothing.
10. **The maintainer is the only unverified terminal.** Every green path bottoms out at an anchor or at
    him; no cycle certifies itself.

_(Amendments follow rule 7's own process.)_
