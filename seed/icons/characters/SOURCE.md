# Illustrated class portraits

Native transparent RGBA generation. No chroma-key workaround.
The 1024px `_hd.png` masters derive 512px runtime PNGs with Lanczos resize. Vite generates dark-matte JPEGs from those PNGs for stable Sui Display URLs, at quality 92 over `#09090e`. JPEG copies are never stored beside the authored portraits.

Identity: authored class models with owner corrections. Senshi are pupil-free, white-eyed templars; the male has long golden-blond hair and the female is blonde. Rojin are elderly grandpa/grandma prospectors. Male Yajin is a skeleton in a blue hood. Each class has distinct facial proportions, age, expression and silhouette.

Style reference: `seed/icons/mobs/demo_goblin_1_hd.png`.
