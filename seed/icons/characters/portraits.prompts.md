# Banner-style class portraits

Generated on November 1, 2026 with the built-in OpenAI image generation tool.
These 24 portraits use the current X banner's hand-drawn voxel cartoon style.

## References and identity

- Primary style reference: `seed/icons/social/x-banner-v3.png`.
- Canonical body and hair references: `seed/models/characters/{class}_{sex}.glb`
  and `seed/models/characters/{class}_{sex}_hair.glb`, from source commit
  `5b6f03e174a4696c4d2a673e2d98f7c51f2441d9`.
- Model references were rendered together with hair attached through the canonical
  head-node transform. The renders supplied identity, not the target style.
- Senshi male, Iyashi female and Yajin male also match their direct banner identities.
  The generated Yajin portrait supplied consistent bust framing for the other portraits.
- Every class retains both canonical sex variants. The unrelated Blast NPC is unchanged.

## Authored assets

The tool returned native transparent RGBA images at 1254 × 1254 pixels. Deterministic
alpha-bounds trimming and proportional fitting within 928 × 928 pixels centers each
portrait on a transparent 1024 × 1024 `_hd.png` master. This adds clear space without
altering the illustration. Lanczos downsampling derives each 512 × 512 runtime PNG.
No chroma key, painted background removal, or replacement rendering is used.

Vite derives the existing stable Sui Display JPEG routes from the runtime PNGs at
quality 92 over `#09090e`. No JPEG copies are stored beside the authored portraits.
Existing shared portrait consumers use these same filenames; there is no separate
turn-card artwork registry.
