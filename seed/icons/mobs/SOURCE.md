# Demo goblin portraits

Generated with the built-in image tool, native transparent alpha. Purchased model renders served only as identity references; Moka artwork served as the style reference.
Each `demo_goblin_{1,3,5}_hd.png` is 1024×1024. Its runtime portrait is a deterministic LANCZOS resize to 512×512.
