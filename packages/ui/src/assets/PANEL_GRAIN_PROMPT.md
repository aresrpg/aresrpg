# Painted panel grain

Generated using the built-in imagegen tool as an opaque material, then deterministically resized to a 512px WebP. It is tiled at 256px and soft-light blended over opaque semantic surface colors.

Use case: stylized-concept material texture. Create one seamless, tileable fine-grain texture for opaque painted game-interface panels. The entire square is a uniform neutral mid-gray material, average color #808080, with extremely subtle tiny irregular grain and faint hand-painted surface variation. Restrained contrast: mostly tones near #787878 to #888888. Fine velvet-like painted slate grain, not stone chunks, not fabric weave, not scratches, not speckles or stars. No lighting hotspot, no vignette, no gradients, no border, no frame, no objects, no text, no icons, no transparency. It will be repeated at 256px and blended subtly over dark charcoal panels, so all areas must be evenly textured with no visible seams or recognizable repeated shapes.
